# Henry Cyril GitHub Pages site

This repository contains a static, GitHub Pages-compatible website for Henry Cyril. The site uses plain HTML, shared CSS, and minimal vanilla JavaScript only.

## Structure

- index.html — home page
- about.html — professional overview
- research.html — research themes and technical interests
- contributions.html — public-safe industry contributions
- publications.html — selected publications
- patents.html — patent section placeholder for verified records
- service.html — professional service section placeholder
- awards.html — awards and recognition section placeholder
- contact.html — professional contact information
- 404.html — custom error page
- assets/css/styles.css — shared styling
- assets/js/main.js — small enhancement script for footer year
- assets/images/ — image assets folder
- assets/documents/ — document assets folder
- robots.txt — search engine crawl instructions
- sitemap.xml — sitemap for GitHub Pages

## Local editing

Open the HTML files directly in a browser, or serve the folder locally with a simple static server if you prefer a local preview.

Example:

```bash
cd /Users/henry/Library/CloudStorage/GoogleDrive-henrypradeep@gmail.com/My\ Drive/EB1A/Github-Website/henrycyril.github.io
python3 -m http.server 8000
```

Then visit http://localhost:8000/ in your browser.

## GitHub Pages deployment

1. Commit the repository changes.
2. In GitHub, open the repository settings.
3. Under Pages, select the main branch and the root folder.
4. Save and allow a few minutes for publishing.

## Notes

- Content is written conservatively and avoids unverified claims.
- Where details are not yet confirmed, the site uses careful public-safe wording or internal TODO comments in the source.
- Relative links are used so the site works correctly on GitHub Pages.
